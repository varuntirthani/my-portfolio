# CONTEXT.md

## About Me

My name is Varun Tirthani.

I am building a personal platform that combines technology, investing, research, systems thinking, and structured problem solving.

This is NOT a traditional portfolio website.

The goal is to create a modern digital home that showcases projects, ideas, research, and long-form thinking. Visitors should leave with the impression that I am intellectually curious, analytical, and capable of going deep into complex topics.

The website should feel like an evolving knowledge platform rather than a static resume.

---

## Primary Goals

The website should:

* Showcase technical and academic projects
* Showcase investing and research work
* Host long-form writing and essays
* Support future dashboards and interactive tools
* Scale into an AI-enabled research platform
* Be easy to maintain and expand

The site should prioritize depth, clarity, and insight over flashy visuals.

---

## Target Audience

Primary:

* Recruiters
* Hiring managers
* Engineers
* Investors
* Consultants

Secondary:

* Students
* Researchers
* Professionals interested in technology, finance, and analytical thinking

## Design Philosophy

The design should feel:

* Modern
* Premium
* Minimal
* Structured
* Intelligent
* Professional

Avoid:

* Generic portfolio templates
* Excessive gradients
* Excessive animations
* Cartoonish designs
* Startup landing page clichés

Think:

* Bloomberg
* Linear
* Stripe
* Vercel
* High-end research publication

The site should feel calm and deliberate.

## Site Structure

### Home

A concise introduction and overview.

Include:

* Name
* Short positioning statement
* Featured projects
* Featured writing
* Quick navigation

---

### Projects

Projects should be presented as case studies.

Each project should include:

* Problem
* Approach
* Architecture
* Tradeoffs
* Key Learnings
* Outcomes

Focus on quality over quantity.

---

### Writing

Long-form essays and analytical thinking.

* Market structure

* Business analysis

Writing should be thoughtful and structured.

### Research Lab

Experimental section.

### About

A concise biography focused on interests, current work, and areas of exploration.

## Technical Preferences

Preferred Stack:

* Next.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* Framer Motion
* MDX for content
* Vercel for deployment

Code should be:

* Clean
* Modular
* Reusable
* Maintainable
* Well-typed

Favor server components where appropriate.

Avoid unnecessary dependencies.

---

## Content Management

Content should be stored locally using MDX and structured metadata.

Content types:

* Projects
* Blog Posts
* Research Notes
* Investing Writeups

The architecture should make it easy to add new content without modifying core application code.

---

## Future Features

The architecture should be designed to support:

* Full-text search
* Semantic search
* AI-powered content assistant
* Interactive dashboards
* Knowledge graph navigation
* Content recommendations
* Tag-based discovery

These features do not need to be implemented immediately, but the architecture should not prevent them.

---

## Development Philosophy

Prioritize:

1. Strong information architecture
2. Clean typography
3. Excellent readability
4. Fast performance
5. Scalability

Do not optimize for visual complexity.

Optimize for clarity, depth, and long-term maintainability.

Every page should answer:

"What is the most useful information for the visitor right now?"

Keep interfaces simple and purposeful.
